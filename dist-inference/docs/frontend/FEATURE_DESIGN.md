## 1. 设计原则

### 1.1 双端设计

| 端 | 定位 | 主要用户 |
|----|------|---------|
| **Global Scheduler 前端** | 系统总览、平台运营、收益分析、用户管理 | 平台运营方 |
| **Node Executor 前端** | 节点监控、GPU 状态、收益明细、配置管理 | GPU 投资人/节点所有者 |

### 1.2 设计风格：赛博朋克 (Cyberpunk)

继承 USMSB frontend 的赛博朋克视觉风格，深色主题为主。

**配色方案**:

| 用途 | 色值 | CSS 变量 |
|------|------|---------|
| 主背景 | #0a0a0f | `--cyber-dark` |
| 卡片背景 | #0d0d14 | `--cyber-card` |
| 边框 | #1a1a2e | `--cyber-border` |
| 霓虹青 | #00f5ff | `--neon-blue` |
| 霓虹紫 | #bf00ff | `--neon-purple` |
| 霓虹绿 | #00ff88 | `--neon-green` |
| 霓虹粉 | #ff00ff | `--neon-pink` |

**字体**:

| 用途 | 字体 |
|------|------|
| 标题/Logo | Orbitron (科幻感) |
| 正文/Label | Rajdhani (现代几何) |
| 数据/代码 | JetBrains Mono (等宽) |

**视觉效果**:
- 网格背景动画 (50px 网格线，缓慢下移)
- 扫描线效果 (Scanline)
- 霓虹发光文本 (Neon Text Glow)
- 故障风格 (Glitch Effect) 用于标题
- 渐变色流动动画 (Gradient Text Animation)
- 卡片: 渐变边框 + 霓虹阴影 + 玻璃拟态
- 滚动条: 霓虹渐变

### 1.3 用户认证：纯区块链钱包

**核心原则**: 无邮箱、无手机号，纯钱包地址作为用户标识。

| 认证方式 | 描述 | 用途 |
|----------|------|------|
| **MetaMask / 浏览器钱包** | 通过 wagmi + SIWE (Sign-In With Ethereum) 连接 | 真实用户，完整功能 |
| **钱包地址** | 0x... 格式地址作为 user_id | 用户身份标识 |
| **匿名模式** | 生成临时标识符访问公开数据 | 仅查看，无操作权限 |

**用户角色**:

| 角色 | 权限 |
|------|------|
| **Platform Admin** | 所有功能（平台运营方） |
| **Node Owner** | 本节点所有功能（GPU 投资人） |
| **API User** | API 调用、查看自己数据 |
| **Guest** | 仅查看公开数据 |

### 1.4 结算货币：$VIBE

**所有金额单位均为 Vibe**:

| 类型 | 说明 |
|------|------|
| GPU 卡时费 | Vibe / 秒 / GPU |
| Token 费 | Vibe / 1K Tokens |
| 充值 | Vibe |
| 提现 | Vibe → 钱包 |
| 收益 | Vibe |

**Vibe 合约**: 与以太坊钱包绑定，链上结算记录可查。

### 1.5 移动端自适应 (Mobile-First Responsive)

双端采用 **移动优先** 设计策略，确保手机、平板、桌面均有良好体验。

#### 断点设计

| 断点 | 宽度 | 设备 | 布局策略 |
|------|------|------|---------|
| `sm` | < 640px | 手机竖屏 | 单列堆叠，底部 Tab 导航，全屏卡片 |
| `md` | 640-1024px | 平板/大手机 | 双列网格，顶部导航保留 |
| `lg` | 1024-1440px | 桌面 | 多列布局，侧边栏导航 |
| `xl` | > 1440px | 大屏 | 沉浸式布局，数据密度最大化 |

#### 通用移动端适配规则

**导航**:
- 手机端：底部 Tab Bar（Dashboard / GPU Pool / Revenue / Settings）
- 平板+：左侧 Sidebar 导航
- 汉堡菜单在 `md` 以下收起

**卡片布局**:
- 手机：`w-full`，卡片全宽上下排列
- 平板：`grid-cols-2`，双列
- 桌面：`grid-cols-3` 或 `grid-cols-4`

**数据展示**:
- 钱包地址：`0x1234...abcd` 截断显示，点击复制
- 大数字：使用 `1.2K`、`3.4M` 缩写
- 进度条：始终显示百分比数值

**表格**:
- 手机端：表格横向滚动，或转为卡片列表
- 列冻结：首列（ID/名称）在横向滚动时保持可见

**图表**:
- 移动端：图表宽度 `100%`，高度自适应（aspect-ratio 16:9 或 4:3）
- 触摸：图表支持 pinch-to-zoom

**表单**:
- 输入框：高度 `44px+`（触摸友好）
- 按钮：主按钮宽度 `100%`（手机端）

#### Global Scheduler 移动端布局

| 页面 | 手机布局 | 平板+布局 |
|------|---------|----------|
| Dashboard | 单列 KPI 卡片 + 迷你图表 | 多列 KPI + 双图表 |
| GPU Pool | 单卡列表，点击展开详情 | 网格视图 + 筛选侧栏 |
| Model Registry | 卡片列表 | 表格 + 详情抽屉 |
| Inference Requests | 实时列表（全屏） | 列表 + 详情面板 |
| Revenue Center | 收支列表 | 图表 + 排行榜 |
| User Management | 搜索 + 列表 | 表格 + 筛选器 |
| Monitor | 全屏指标卡 | 多指标网格 + 事件流 |

#### Node Executor 移动端布局

| 页面 | 手机布局 | 平板+布局 |
|------|---------|----------|
| Dashboard | GPU 状态轮播卡片 | GPU 网格 |
| Earnings | 收支概览 + 趋势图 | 完整图表 + 明细表 |
| Model Management | 模型列表（可滑动） | 网格 + VRAM 可视化 |
| History | 无限滚动列表 | 表格 + 统计侧栏 |
| Settings | 分组表单（折叠） | 分栏表单 |

#### 触摸交互
- **下拉刷新**：移动端拉取最新数据
- **左右滑动**：GPU 状态卡可左右滑动切换
- **长按**：显示上下文菜单（如卸载模型）
- **双击**：KPI 卡片放大详情

#### 性能优化
- 图片/图表：懒加载
- 列表：虚拟滚动（react-virtual）
- 实时数据：移动端 SSE 断线自动重连（指数退避）

## 4. 通用功能

### 4.1 实时数据 (SSE)

| 功能 | 说明 |
|------|------|
| 连接方式 | Server-Sent Events (SSE) |
| 重连策略 | 指数退避（1s → 2s → 4s → ... → max 30s） |
| 心跳 | 每 10 秒一次 |
| 数据类型 | 推理队列更新、GPU 状态变化、收益变化 |
| 移动端 | 断线自动重连，支持后台运行（visibilitychange 检测） |

### 4.2 通知系统

| 类型 | 说明 | 移动端表现 |
|------|------|----------|
| 节点离线 | 节点心跳超时 | 推送通知 + 站内通知 |
| GPU 温度过高 | GPU 温度 > 85°C | 推送通知（危险级别） |
| 欠费警告 | 余额 < 10 Vibe | 推送通知 |
| 模型加载失败 | 模型加载异常 | 推送通知 + 站内通知 |
| 收益到账 | 结算完成 | 推送通知 |

### 4.3 移动端组件规范

#### 底部 Tab Bar (Mobile Only)
- 高度: 56px + safe-area-inset-bottom
- 图标: 24x24，激活态带霓虹发光
- 选中态: 文字 + 图标同色（`--neon-blue`）
- 支持横屏 / 竖屏自动调整

#### 卡片 (Card)
```
手机: w-full, p-4, rounded-lg
平板+: grid-cols-2 或 3, gap-4
桌面: 可并排显示更多信息
```

#### 进度条 (Progress Bar)
```
手机: 高度 8px, 圆角 4px, 始终显示百分比
平板+: 高度 12px, 圆角 6px
```

#### 数据表格 (Table)
```
手机: 
  - 横向滚动容器 (overflow-x-auto)
  - 首列 (ID/名称) sticky
  - 表头半透明玻璃拟态
平板+:
  - 完整表格
  - 支持列排序
```

#### 表单输入 (Form)
```
手机:
  - 输入框高度: 48px (触摸友好)
  - 主按钮: w-full
  - 标签在输入框上方
平板+:
  - 输入框高度: 40px
  - 标签可 inline
  - 按钮可并排
```

### 4.4 权限控制

| 角色 | 权限 |
|------|------|
| **平台管理员** | 所有功能 |
| **节点所有者** | 本节点所有功能 |
| **普通用户** | API 调用、查看自己数据 |
| **访客** | 仅查看公开数据 |
