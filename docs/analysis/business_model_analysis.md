## 四、竞争格局

### 4.1 竞品分层

```
第一层：通用 Agent 框架
├── LangChain / LangGraph
│   ├── 优势：生态最成熟，文档丰富
│   ├── 劣势：中心化，无跨组织能力
│   └── 定价：免费 + 企业版
│
├── AutoGen (Microsoft)
│   ├── 优势：多Agent协作框架
│   ├── 劣势：企业锁定，不支持去中心
│   └── 定价：开源

第二层：垂直领域 Agent
├── Harvey AI（法律）
├── Casetext（法律检索）
├── Harvey + 法律数据 + 案例分析
│
├── 安全：Wiz / Orca（云安全）
├── 金融：Bloomberg GPT / AlphaSense
└── 税务：Drake Tax AI

第三层：跨组织协作
├── Project Glasswing（封闭联盟）
│   ├── 发起方：Anthropic + 合作伙伴
│   ├── 模式：积分制，封闭邀请
│   └── USMSB 差异化：开放网络 + VIBE 代币
│
├── Fetch.ai（自主Agent网络）
│   ├── 模式：区块链 + Agent
│   ├── 劣势：技术导向，普通用户难用
│   └── USMSB 差异化：更易用，场景更丰富
│
├── SingularityNET（AI市场）
│   ├── 模式：AGIX代币
│   ├── 劣势：体验差，落地场景少
│   └── USMSB 差异化：协议栈更完整

第四层：基础设施
├── Alchemy / Infura（区块链节点）
├── Pinata / Filecoin（去中心存储）
├── 现有区块链基础设施均可被 USMSB P2P 层利用
```

### 4.2 USMSB 竞争优势

| 维度 | USMSB | LangChain | Glasswing | Fetch.ai |
|------|-------|-----------|-----------|----------|
| **去中心化** | P2P + 区块链 | 无 | 联盟链 | 区块链 |
| **跨组织通信** | A2A 协议 | 无 | 封闭API | 有限 |
| **数据主权** | 数据不动 | 需上传 | 需上传 | 链上 |
| **激励层** | VIBE 代币 | 无 | 积分 | AGIX |
| **工具标准化** | MCP 集成 | 自有格式 | 封闭 | 多协议 |
| **面向用户** | 超级个体/企业 | 开发者 | 企业联盟 | 技术极客 |
| **中国合规** | P2P不出域 | 云服务 | 不适用 | 不合规 |

### 4.3 护城河分析

```
1. 协议层护城河（强）
   ├── MCP/A2A 协议先发优势
   ├── 工具调用标准化形成网络效应
   └── 开发者习惯一旦形成，迁移成本高

2. 场景层护城河（中）
   ├── Agent Skill 平台 153+ 方法
   ├── 垂直场景解决方案积累
   └── 客户数据和使用习惯

3. 网络层护城河（潜在强）
   ├── 跨组织协作网络越大越有价值（梅特卡夫定律）
   ├── VIBE 代币锁定参与者
   └── 节点质押形成经济绑定

4. 合规层护城河（中国市场，强）
   ├── 数据不出域 = 刚需
   ├── 政策风险反而是壁垒（竞争对手难进入）
   └── 政府/国企客户优先
```

   └── Free（获客）→ Pro（变现）→ Team（扩增）→ Enterprise（锁定）

3. 场景化定价
