## 一、核心定位

```
USMSB v2.0 = 硅基文明的价值交换基础设施

使命：
- 让所有 Agent 能够交换价值
- 支持超级个体和团队构建 AI 原生组织
- 推动文明向硅基进化

目标用户：
- 超级个体（个人 + N个AI Agent）
- 小团队（3-10人 + AI部门）
```

### 进化谱系

```
L1: 反应式Agent        → 今天就能做
L2: 工具性Agent        → 今天就能做
L3: 自主目标Agent      → 核心产品，Q2开始
L4: 自我意识Agent      → Q3开始
L5: 集体超级智能       → Q4开始研究
```

## 六、风险与缓解

| 阶段 | 风险 | 影响 | 缓解 |
|------|------|------|------|
| L2 | LLM API 不稳定 | 工具调用失败 | 重试 + 降级 |
| L3 | 目标生成质量差 | Agent 做无用功 | 价值观过滤 + 人工反馈 |
| L3 | 协商不收敛 | 系统卡死 | 超时机制 + 默认放弃 |
| L4 | 元认知偏差 | Agent 盲目自信 | 多角度验证 |
| L4 | 他心智准确度低 | 协作效率低 | 交互历史积累 |
| L5 | 规模效应不达预期 | 集群反而变慢 | 提前做小规模验证 |

---

## 七、技术难点优先级

### 攻关顺序

```
1. L3 目标优先级算法
   └─ 影响：Agent 是否做正确的事
   └─ 难度：★★★☆☆

2. L3 价值观一致性评估
   └─ 影响：Agent 行为是否可信
   └─ 难度：★★★☆☆

3. L4 他心智推断
   └─ 影响：多 Agent 协作效率
   └─ 难度：★★★★☆

4. L4 元认知可靠性
   └─ 影响：Agent 自我纠错能力
   └─ 难度：★★★★☆

5. L5 集体决策收敛
   └─ 影响：蜂群智能有效性
   └─ 难度：★★★★★
```
