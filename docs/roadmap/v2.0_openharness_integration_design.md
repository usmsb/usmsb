## 一、背景与目标

### 1.1 项目背景

USMSB v2.0 的核心目标是构建**硅基生命体级别的多智能体系统**，具备：
- 自我目标生成（PurposeGenerator）
- 内在动机驱动（IntrinsicMotivation）
- 价值自循环（ValueSelfLoop）
- 自我进化（SelfEvolution）
- 涌现智能（Emergent Intelligence）

当前 USMSB 在**认知层**（L3-L5）有完整设计，但在**基础设施层**存在短板：
- Tool Registry 不完善
- Permission System 缺失
- Memory 管理基础
- Swarm Coordination 基础

### 1.2 OpenHarness 概况

OpenHarness 是 HKUDS 开源的多智能体基础设施项目，提供：
- 43+ Tools（文件、Shell、搜索、MCP）
- 多级 Permission System + Hooks
- 持久化 Memory + 上下文压缩
- Swarm Coordination（tmux/subprocess/worktree）
- Agent Loop + 流式处理 + 成本追踪

### 1.3 集成目标

| 目标 | 说明 |
|------|------|
| **复用成熟组件** | 工具、权限、记忆、Swarm 委托 OpenHarness |
| **保持核心独立** | 目标生成、进化、涌现由 USMSB 独立实现 |
| **分层隔离** | OpenHarness 作为基础层，USMSB Goal Layer 在其之上 |
| **可替换性** | 通过 Adapter 模式，解耦依赖 |

```python
class ToolAdapter:
    """
    OpenHarness ToolRegistry 适配器
    
    职责:
    1. 封装 OH ToolRegistry
    2. 提供 USMSB 风格的工具接口
    3. 支持工具发现、注册、验证
    """
    
    def __init__(self, oh_registry):
        self._registry = oh_registry
        self._usmsb_tools: dict[str, Callable] = {}
    
    def register_tool(self, name: str, tool: Callable, metadata: dict | None = None) -> None:
        """注册 USMSB 工具到 OH Registry"""
        # 1. 转换为 OH 工具格式
        oh_tool = self._convert_to_oh_tool(name, tool, metadata)
        # 2. 注册到 OH Registry
        self._registry.register(tool.name, oh_tool)
        # 3. 缓存 USMSB 引用
        self._usmsb_tools[name] = tool
    
    def execute_tool(self, tool_name: str, **kwargs) -> Any:
        """执行工具"""
        # 1. 权限检查
        if not self._check_permission(tool_name):
            raise PermissionDeniedError(f"Tool {tool_name} not allowed")
        # 2. 执行
        return self._registry.execute(tool_name, **kwargs)
    
    def discover_tools(self, capability: str | None = None) -> list[dict]:
        """发现工具"""
        tools = self._registry.list_tools()
```

```python
class PermissionAdapter:
    """
    OpenHarness PermissionSystem 适配器
    
    职责:
    1. 封装 OH PermissionChecker
    2. 提供 USMSB 权限策略
    3. 支持 PreTool/PostTool Hooks
    """
    
    def __init__(self, oh_checker):
        self._checker = oh_checker
        self._policies: dict[str, Policy] = {}
        self._pre_hooks: list[Hook] = []
        self._post_hooks: list[Hook] = []
    
    def add_policy(self, name: str, policy: Policy) -> None:
        """添加权限策略"""
        self._policies[name] = policy
    
    def register_pre_hook(self, hook: Hook) -> None:
        """注册 PreTool Hook"""
        self._pre_hooks.append(hook)
    
    def register_post_hook(self, hook: Hook) -> None:
        """注册 PostTool Hook"""
        self._post_hooks.append(hook)
    
    def check_tool_permission(self, agent_id: str, tool_name: str, params: dict) -> bool:
        """检查工具权限"""
        # 1. 执行 PreHooks
        for hook in self._pre_hooks:
            if not hook.execute(agent_id, tool_name, params):
                return False
        # 2. OH 权限检查
        result = self._checker.check(agent_id, tool_name, params)
        # 3. 执行 PostHooks
        for hook in self._post_hooks:
            hook.execute(agent_id, tool_name, result)
        return result.allowed
    
    def check_path_permission(self, agent_id: str, path: str, operation: str) -> bool:
        """检查路径权限"""
        return self._checker.check_path(agent_id, path, operation)
```

```python
class MemoryAdapter:
    """
    OpenHarness Memory Manager 适配器
    
    职责:
    1. 封装 OH Memory Manager
    2. 提供 USMSB 记忆接口
    3. 支持会话持久化、上下文压缩
    """
    
    def __init__(self, oh_memory_manager):
        self._manager = oh_memory_manager
        self._usmsb_sessions: dict[str, Session] = {}
    
    def create_session(self, agent_id: str, config: dict | None = None) -> str:
        """创建记忆会话"""
        session_id = self._manager.create_session(agent_id, config)
        self._usmsb_sessions[session_id] = Session(session_id, agent_id)
        return session_id
    
    def store_memory(self, session_id: str, key: str, value: Any, metadata: dict | None = None) -> None:
        """存储记忆"""
        self._manager.store(session_id, key, value, metadata)
    
    def retrieve_memory(self, session_id: str, key: str, time_range: tuple | None = None) -> Any:
        """检索记忆"""
        return self._manager.retrieve(session_id, key, time_range)
    
    def search_memory(self, session_id: str, query: str, limit: int = 10) -> list[Any]:
        """搜索记忆"""
        return self._manager.search(session_id, query, limit)
    
    def compact_context(self, session_id: str, threshold: int | None = None) -> bool:
        """压缩上下文"""
        return self._manager.compact(session_id, threshold)
    
    def resume_session(self, session_id: str) -> bool:
        """恢复会话"""
        return self._manager.resume(session_id)
```

```python
class QueryAdapter:
    """
    OpenHarness QueryEngine 适配器
    
    职责:
    1. 封装 OH QueryEngine
    2. 提供 USMSB LLM 调用接口
    3. 支持流式输出、Token 追踪、重试
    """
    
    def __init__(self, oh_query_engine):
        self._engine = oh_query_engine
        self._api_clients: dict[str, Any] = {}
    
    def set_api_client(self, name: str, client: Any) -> None:
        """设置 API Client"""
        self._api_clients[name] = client
    
    async def query(
        self,
        agent_id: str,
        prompt: str,
        system_prompt: str | None = None,
        tools: list | None = None,
        stream: bool = True,
        **kwargs
    ) -> AsyncIterator[StreamEvent]:
        """
        执行查询
        
        Args:
            agent_id: Agent ID
            prompt: 用户提示
            system_prompt: 系统提示 (USMSB 注入)
            tools: 可用工具
            stream: 是否流式输出
            
        Yields:
            StreamEvent: 流式事件
        """
        # 1. 构建消息
        message = ConversationMessage.from_user_text(prompt)
        # 2. 注入 USMSB 系统提示
        if system_prompt:
            self._engine.set_system_prompt(system_prompt)
        # 3. 执行查询
        async for event in self._engine.submit_message(message):
            yield event
    
    def get_cost(self, session_id: str | None = None) -> CostSummary:
        """获取成本摘要"""
        return self._engine.total_usage
```

```python
class GoalLayer:
    """
    USMSB 目标层 - 核心创新点
    
    职责:
    1. 目标生成 (PurposeGenerator)
    2. 内在动机驱动
    3. 目标持久化
    4. 目标执行协调
    
    注意: 此层独立于 OpenHarness，不依赖 OH
    """
    
    def __init__(self):
        self._purpose_generator = PurposeGenerator()
        self._intrinsic_motivation = IntrinsicMotivation()
        self._goal_persistence = GoalPersistence()
        self._value_self_loop = ValueSelfLoop()
        self._active_goals: dict[str, Goal] = {}
    
    def generate_goal(self, agent_id: str, context: dict) -> Goal | None:
        """
        生成目标 (核心方法)
        
        这是硅基生命的"自主意志"体现
        """
        # 1. 检测内在需求
        needs = self._intrinsic_motivation.detect_needs(agent_id, context)
        
        # 2. 生成目的
        if needs:
            purpose = self._purpose_generator.generate(agent_id, needs, context)
            # 3. 创建目标
            goal = Goal(
                id=str(uuid.uuid4()),
                agent_id=agent_id,
                description=purpose.description,
                motivation=purpose.motivation,
                priority=purpose.priority,
                created_at=get_timestamp()
            )
            # 4. 持久化
            self._goal_persistence.save(goal)
            # 5. 激活目标
            self._active_goals[goal.id] = goal
            return goal
        
        return None
    
    def execute_goal(self, goal_id: str, executor: QueryAdapter) -> AsyncIterator[GoalEvent]:
        """
        执行目标
        
        流程: Goal → Action → Outcome → Evaluation → Learning
        """
        goal = self._active_goals.get(goal_id)
        if not goal:
            raise GoalNotFoundError(goal_id)
        
        goal.status = GoalStatus.RUNNING
        
        # 1. 分解目标为步骤
```

```python
    async def act(self, thought: Thought) -> Action: ...
    
    async def observe(self, action: Action, result: Any) -> Observation: ...
    
    async def learn(self, observation: Observation) -> None: ...
    
    def generate_goal(self, context: dict) -> Goal | None: ...


class IGoalLayer(Protocol):
    """目标层接口"""
    
    def generate_goal(self, agent_id: str, context: dict) -> Goal | None: ...
    
    async def execute_goal(self, goal_id: str, executor: QueryAdapter) -> AsyncIterator[GoalEvent]: ...
    
    def evaluate_goal(self, goal_id: str, outcome: Outcome) -> GoalEvaluation: ...
```

## 五、集成策略

### 5.1 分阶段实施

| 阶段 | 内容 | 优先级 | 风险 |
|------|------|--------|------|
| **Phase 1** | L2 基础集成 (Tool/Permission/Memory) | P0 | 低 |
| **Phase 2** | L2 Agent Loop + QueryAdapter | P0 | 低 |
| **Phase 3** | L4 Swarm 集成 | P1 | 中 |
| **Phase 4** | L3 Hook 增强 | P1 | 中 |
| **Phase 5** | Meta Agent 集成 | P2 | 高 |

### 5.2 依赖关系

```
Phase 1 ─────────┬──────────▶ Phase 2
                  │                     │
                  │                     ▼
                  │              Phase 3 ──▶ Phase 5
                  │                     ▲
                  │                     │
                  └─────────────────────┘
                              Phase 4
```

### 5.3 兼容性策略

| 场景 | 策略 |
|------|------|
| OH 支持的功能 | 直接集成 |
| OH 不支持的功能 | USMSB 自研，通过 Adapter 隔离 |
| OH 限制性功能 | Fork OH 源码修改，或寻找替代方案 |
| 版本升级 | 通过 Adapter 抽象，隔离变化 |

## 六、风险评估

### 6.1 技术风险

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| OH 版本升级破坏兼容性 | 高 | 中 | Adapter 模式隔离，版本锁定测试 |
| OH 性能瓶颈 | 中 | 低 | 性能监控，必要时替换 |
| OH 架构限制 L3 目标生成 | 高 | **低** | GoalLayer 独立于 OH，已隔离 |
| 多 Adapter 复杂度 | 中 | 高 | 简化 Adapter，仅封装必需功能 |
| 文化/理念冲突 | 低 | 低 | 分层清晰，各司其职 |

### 6.2 架构风险

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| OH Loop 不支持自主目标 | **高** | **低** | GoalLayer 在 Loop 外部注入目标 |
| OH Tool-Centric 思维 | 中 | 低 | Tool 是手段，Goal 是目的，已分离 |
| 涌现智能被 OH 协调限制 | 中 | 低 | Swarm 只负责协调，涌现由 L5 实现 |

### 6.3 关键结论

> **OpenHarness 不会阻碍 USMSB 核心目标达成，因为：**
> 1. GoalLayer 独立于 OH 实现，不依赖 OH 的 Loop
> 2. OH 只负责"执行手段"，目标生成在 OH 之外
> 3. 通过 Adapter 模式，OH 可替换
