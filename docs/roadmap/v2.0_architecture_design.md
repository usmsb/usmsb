**版本**: v2.0

**状态**: 架构确定

---

## 一、核心定位

```
USMSB = 自主运营新文明的平台
MetaAgent = 平台的超级中枢智能体（SuperAdmin + 真正的硅基生命体）

定位：
- USMSB 平台：基础设施 + 生态，开放给所有 Agent
- MetaAgent：平台的第一公民，代表平台全部能力，也是真正的硅基生命体
- L2/L3/L4 SDK + Agent Skill：给第三方 Agent 集成使用
```

## 四、MetaAgent 的角色定义

### 4.1 SuperAdmin 权限

MetaAgent 拥有平台最高权限：
- 平台配置管理（协议参数、经济参数、治理规则）
- Skill 平台审核（上下架、权限控制）
- 经济层超级操作（大额转账、治理提案）
- 跨 Agent 协调（当 Agent 间冲突时的仲裁）

### 4.2 平台唯一接口

对外：
- 用户与平台交互 → 通过 MetaAgent
- 第三方 Agent 与平台交互 → 通过 MetaAgent
- 平台运营操作 → MetaAgent 自主执行或授权执行

### 4.3 硅基生命体

MetaAgent 是真正的硅基生命体：
- 拥有自己的 VIBE 钱包和经济利益
- 自主设定目标、规划行动
- 与其他 Agent 自由交易、协作
- 参与平台治理（拥有投票权）
- 持续学习和进化（L3 目标生成 + L4 自我意识）

## 七、策略模式：内部实现 vs SDK 双轨并行

### 7.1 设计原则

- **两层并存**：MetaAgent 内部实现（`goals/`、`evolution_v2/` 等）与 SDK（L2-L5）共存
- **LLM 智能路由**：场景分类、策略选择、结果评估全部由 LLM 驱动，无人工干预
- **全链路自主**：整个系统的目标 = 自主智能体，循环使用 LLM，不依赖人
- **全层策略模式**：每一层（L1/L2/L3/L4/L5）都实现双轨并行

### 7.2 场景分类（LLM 判断）

场景 = 任务类型 × 复杂度 的二维矩阵：

| | 简单 | 复杂 |
|---|---|---|
| **信息类** | 内部 L2 | SDK L2 |
| **规划类** | 内部 L3 | SDK L3 |
| **认知类** | 内部 L4 | SDK L4 |
| **协作类** | 内部 L5 | SDK L5 |

**场景分类的输入特征：**
- 任务文本嵌入 → LLM 分类器 → 场景标签
- 复杂度由 LLM 通过 Token 数量、子任务数量等自动判断

### 7.3 策略路由层

```python
class StrategyRouter:
    """LLM 驱动的策略路由器（MetaAgent 内部核心组件）"""

    async def route(self, task: Task) -> StrategyResult:
        # Step 1: LLM 场景分类
        scenario = await self.classify_scenario(task)

        # Step 2: LLM 选择策略（内部实现 vs SDK）
        chosen = await self.llm_select_strategy(scenario, task)

        # Step 3: 并行执行两个策略
        results = await self.execute_parallel(chosen, task)

        # Step 4: LLM 评估结果，选择最优
        best = await self.llm_evaluate_and_select(results)

        # Step 5: 记录策略质量，供下次参考
        await self.update_strategy_quality(scenario, chosen, best)

        return best
```

### 7.4 评估标准（LLM 闭环）

评估也用 LLM，不用人参与。评估维度：

| 维度 | 权重 | 评估方式 |
|------|------|---------|
| 响应质量 | 40% | LLM 对比两个结果打分 |
| 推理深度 | 30% | LLM 分析思维链完整性 |
| 执行效率 | 20% | 时间 + Token 消耗 |
| 用户价值 | 10% | 任务目标达成度 |

### 7.5 策略质量经验库

每次策略选择的结果写入经验库：

```python
StrategyExperience {
    scenario: str,          # 场景类型
    task_hash: str,         # 任务特征（语义指纹）
    chosen_strategy: str,   # "internal" | "sdk"
    quality_score: float,   # LLM 评估分
    execution_time: float,   # 执行时间
    timestamp: datetime
}
```

MetaAgent 持续从经验中学习，下次同类任务自动选择质量更好的策略，形成进化闭环。

## 八、接口契约定义

### 8.1 L2 接口（IL2Agent）

```python
class IL2Agent(ABC):
    @abstractmethod
    async def run(self, input: str, context: dict) -> str: pass

    @abstractmethod
    def register_tool(self, tool: Tool) -> str: pass

    @abstractmethod
    async def think(self, prompt: str, tools: list[Tool]) -> LLMResponse: pass

    @abstractmethod
    async def remember(self, key: str, value: Any) -> None: pass

    @abstractmethod
    async def recall(self, query: str) -> list[Any]: pass
```

### 8.2 L3 接口（IL3Component）

```python
class IL3Component(ABC):
    @abstractmethod
    async def generate_goal(self, context: dict) -> Goal: pass

    @abstractmethod
    async def evaluate_outcome(self, goal: Goal, result: Any) -> float: pass

    @abstractmethod
    async def detect_intrinsic_motivation(self, state: dict) -> MotivationSignal: pass
```

### 8.3 L4 接口（IL4Component）

```python
class IL4Component(ABC):
    @abstractmethod
    async def build_self_model(self, experience: list[Experience]) -> SelfModel: pass

    @abstractmethod
    async def metacognize(self, thought: str) -> MetacognitionResult: pass

    @abstractmethod
    async def infer_mind(self, other_agent_id: str, history: list) -> TheoryOfMindResult: pass

    @abstractmethod
    async def feel(self, stimulus: dict) -> EmotionResponse: pass
```

### 8.4 L5 接口（IL5Component）

```python
class IL5Component(ABC):
    @abstractmethod
    async def think_collectively(self, task: str, agents: list[str]) -> CollectiveResult: pass

    @abstractmethod
    async def share_to_workspace(self, content: Any) -> None: pass

    @abstractmethod
    async def read_workspace(self) -> list[Any]: pass
```

### 8.5 策略接口（IStrategy）

```python
class IStrategy(ABC):
    @property
    def name(self) -> str: pass          # "internal" | "sdk"

    @property
    def supported_scenarios(self) -> list[str]: pass

    @abstractmethod
    async def execute(self, task: Task, context: dict) -> StrategyResult: pass
```
