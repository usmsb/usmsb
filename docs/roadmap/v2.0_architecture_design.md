# USMSB v2.0 架构设计

**版本**: v1.0
**日期**: 2026-04-15
**状态**: 架构确定

---

## 一、设计原则

1. **L2-L5 独立可用** - 可单独使用，也可组合使用
2. **可组合可串行** - 灵活调用方式
3. **harness 参考 OpenHarness** - MAS 工程基础设施层
4. **OH 可选集成** - 保留 1.0 成熟能力，作为可选增强

---

## 三、模块职责

### L1 - 规则引擎 (Rule Engine)
```python
# 位置: usmsb_sdk/l1/
# 职责: 快速规则匹配，最短路劲响应
# 依赖: 无
# 可独立使用: ✅
```
- Stimulus → Response 快速映射
- 兜底策略

### L2 - 工具性 Agent (Tool-based Agent)
```python
# 位置: usmsb_sdk/l2/
# 职责: LLM + 工具调用 + 记忆
# 依赖: L1
# 可独立使用: ✅
# 可组合使用: ✅
```
- LLM 推理
- 工具注册与调用 (ToolRegistry)
- 分层记忆 (AgentMemory)
- ReAct 框架

### L3 - 目标生成 (Goal Generation)
```python
# 位置: usmsb_sdk/l3/
# 职责: 自主目标生成、动机驱动
# 依赖: L2
# 可独立使用: ✅
# 可组合使用: ✅
```
- PurposeGenerator - 目的生成
- IntrinsicMotivationEngine - 内在动机
- ValueSelfLoop - 价值自循环
- SelfEvolutionEngine - 自我进化

### L4 - 自我意识 (Self-Awareness)
```python
# 位置: usmsb_sdk/l4/
# 职责: 自我建模、元认知、情感
# 依赖: L3
# 可独立使用: ✅
# 可组合使用: ✅
```
- SelfModel - 自我模型
- Metacognition - 元认知
- TheoryOfMind - 心智理论
- EmotionalArchitecture - 情感架构

### L5 - 集体智能 (Collective Intelligence)
```python
# 位置: usmsb_sdk/l5/
# 职责: 多 Agent 协作、集体决策
# 依赖: L4
# 可独立使用: ✅
# 可组合使用: ✅
```
- GlobalWorkspace - 全局工作空间
- CollectiveMemory - 集体记忆
- CollectiveDecisionMaking - 集体决策
- EmergentGovernance - 涌现治理

### harness - MAS 工程基础设施
```python
# 位置: usmsb_sdk/harness/
# 职责: 类似 OpenHarness 的基础设施层
# 依赖: 无 (被上层调用)
# 可被集成: ✅
```
参考 OpenHarness 的设计：
- **ExecutionEngine** - 目标执行、工具调用、错误处理
- **KnowledgeLayer** - 知识供给 (参数化/非参数化/经验)
- **PolicyRuntime** - 风险门控 (硬性/软性/动态规则)
- **GovernanceLayer** - 治理运营、经验沉淀
- **ExecutionOrchestrator** - 多 Agent 编排

### adapters/openharness - 可选增强 (Optional Enhancement)
```python
# 位置: usmsb_sdk/adapters/openharness/
# 职责: OpenHarness 能力注入
# 依赖: harness + OpenHarness 库
# 可选: ✅ (默认不启用)
```
- QueryAdapter - LLM 调用
- ToolAdapter - 工具执行
- SwarmAdapter - 多 Agent 协作
- HookAdapter - 自我观察
- MemoryAdapter - 持久化记忆

## 四、组合方式

### 4.1 独立使用
```python
# 单独使用 L2
agent = L2Agent()
result = await agent.run("帮我查天气")

# 单独使用 L3
pg = PurposeGenerator()
goal = await pg.generate()

# 单独使用 L5
collective = L5CollectiveIntelligence()
decision = await collective.decide(topic)
```

### 4.2 串行组合
```python
# L1 → L2 → L3 → L4 → L5 串行
agent = L2Agent()
agent = L3Wrapper(agent)  # 添加目标生成
agent = L4Wrapper(agent)  # 添加自我意识
agent = L5Wrapper(agent)  # 添加集体智能
```

### 4.3 并行组合
```python
# 多个 L2 Agent 并行，L5 协调
collective = L5CollectiveIntelligence()
agents = [L2Agent(id=f"agent_{i}") for i in range(3)]
collective.add_members(agents)
result = await collective.think_collectively(task)
```

### 4.4 SDK 集成
```python
# 第三方应用集成 L2-L5
from usmsb_sdk.l2 import L2Agent
from usmsb_sdk.l3 import PurposeGenerator

class MyApp:
    def __init__(self):
        self.agent = L2Agent()
        self.goals = PurposeGenerator(self.agent)
```

## 五、OpenHarness 集成策略

### 5.1 集成原则
- **不替换**原有 1.0 成熟能力
- **可选插件**，通过配置启用
- **适配器模式**，解耦依赖

### 5.2 集成架构
```
                    ┌──────────────────┐
                    │   MetaAgent /    │
                    │   L2Agent /      │
                    │   Custom Agent   │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │   harness/        │
                    │ (基础设施层)       │
                    └────────┬─────────┘
                             │
              ┌──────────────┴──────────────┐
              │                              │
     ┌────────▼────────┐          ┌─────────▼────────┐
     │  Default (1.0)  │          │  OpenHarness     │
     │  原有实现       │          │  (可选插件)       │
     │  ✅ 成熟稳定    │          │  ⚡ 高性能        │
     └─────────────────┘          └──────────────────┘
```

### 5.3 启用 OH 增强
```python
# 方式 1: 配置启用
config = MetaAgentConfig(
    use_openharness=True,
    oh_version=">=0.1.6",
)

# 方式 2: 手动注入
from usmsb_sdk.adapters.openharness import OpenHarnessIntegration

oh = OpenHarnessIntegration()
await oh.initialize()

agent = MetaAgent(config)
agent.enable_oh(oh)
```

## 六、模块接口定义

### L2 Agent 接口
```python
class IL2Agent(ABC):
    """L2 Agent 标准接口"""
    
    @abstractmethod
    async def run(self, input: str) -> str:
        """执行输入"""
        pass
    
    @abstractmethod
    def register_tool(self, tool: Tool) -> str:
        """注册工具"""
        pass
    
    @abstractmethod
    async def think(self, prompt: str) -> str:
        """LLM 推理"""
        pass
```

### L3 接口
```python
class IL3Component(ABC):
    """L3 目标生成标准接口"""
    
    @abstractmethod
    async def generate_goal(self, context: dict) -> Goal:
        """生成目标"""
        pass
    
    @abstractmethod
    async def evaluate_outcome(self, goal: Goal, result: Any) -> float:
        """评估结果"""
        pass
```

### harness 接口
```python
class IExecutionEngine(ABC):
    """执行引擎标准接口"""
    
    @abstractmethod
    async def execute(self, goal: Goal, tools: list[Tool]) -> ExecutionResult:
        """执行目标"""
        pass
    
    @abstractmethod
    async def execute_tool(self, tool: Tool, params: dict) -> Any:
        """执行工具"""
        pass
```
