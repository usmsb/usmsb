## 四、VIBE Token 经济模型

### 4.1 Token定位

```
VIBE = Utility Token（实用型代币）

不是证券 → 不承诺升值/分红
不是货币 → 不能当钱花
不是股票 → 不代表公司股权

用途：
├── 支付生态内服务
├── 激励贡献者
├── 享受生态升值
└── 社区治理投票
```

### 4.2 Token分配

```
┌────────────────────────────────────────┐
│   VIBE Token 分配                       │
├────────────────────────────────────────┤
│                                        │
│   社区基金      40%                    │
│   团队/顾问     15%                    │
│   早期投资者    20%                    │
│   生态激励      15%                    │
│   国库          10%                    │
│                                        │
└────────────────────────────────────────┘

社区基金（40%）：
- 用于生态激励
- 挖矿奖励
- 开发者 Grant
- 用户空投

释放机制：
- 社区基金：按需释放
- 团队：6个月后解锁，36个月线性释放
- 早期投资者：6个月解锁，12个月线性释放
```

### 4.3 Token使用场景

```
场景1：支付会员
├── 月卡：100 VIBE/月（原价125 VIBE）
├── 年卡：1000 VIBE/年
└── 折扣激励用户持有和使用VIBE

场景2：购买高级服务
├── 高级Agent：50 VIBE/次
├── 专业报告：100 VIBE/份
└── 优先队列：20 VIBE/次

场景3：推荐奖励
├── 好友付费 → 邀请人获得50 VIBE
├── 好友首次付费金额的50%换算
└── 单层奖励，合规设计

场景4：质押收益
├── 质押VIBE成为验证节点
├── 年化收益 8-15%
└── 手续费分成

场景5：生态治理
├── 持有VIBE可投票
├── 决定协议升级
├── 决定生态基金使用
```

### 4.4 钱包系统

```
用户钱包 = Web3抽象化，隐藏复杂性

注册流程：
1. 输入手机号
2. 系统自动创建钱包
3. 助记词让用户备份（可选择云端托管）
4. 获得100 VIBE体验金

用户界面：
┌─────────────────────────────────┐
│                                 │
│   💎 VIBE钱包                    │
│                                 │
│   余额：1,234.56 VIBE           │
│   ≈ ¥567.89                    │
│                                 │
│   📈 今日 +12.3%               │
│   💰 累计收益 +¥234.56          │
│                                 │
│   [充币] [消费] [转账] [质押]    │
│                                 │
└─────────────────────────────────┘
```

### 4.5 充币方式

```
Option A：C2C撮合（推荐）
- 用户A想卖VIBE，用户B想买
- 平台撮合，类似OTCBTC
- 平台收取手续费

Option B：合规交易所API
- 对接合规交易所
- 用户直接用法币买VIBE
- 平台中间商赚差价

Option C：内置Swap
- 用户充值人民币
- 平台自动换成VIBE
- 用户无感知

推荐：C2C + 内置Swap混合
```

- 产品用人民币定价
- Token激励在境外合规处理
- 用户个人行为自担风险
```

### 7.2 合规清单

```
✅ Utility Token（非证券）
✅ 单层推荐（非多级分销）
✅ 用户自愿持有
✅ 风险提示
❌ 不承诺升值
❌ 不保证收益
❌ 不在美国等地公募
❌ 不在中国大陆运营
```

### 7.3 Token性质定义

```
VIBE = 实用型代币

功能：
1. 支付生态内服务
2. 激励生态贡献者
3. 治理投票权
4. 质押获得收益

风险提示（强制显示）：
"VIBE Token是实用型代币，价值由市场决定，
可能升值也可能贬值。投资有风险，请理性对待。"

### 8.2 推广路径

```
第一阶段：体验
让用户免费用
体验"张嘴就来"的快感
不需要理解原理

第二阶段：依赖
用户发现"哎真方便"
开始用AI做更多事
每天离不开

第三阶段：觉醒
用户突然意识到：
"等等，我一直在定义意图？"
"所以我是……意图定义者？"

第四阶段：主动
用户开始主动思考：
"我还有什么想要实现的？"
```

### 8.3 裂变机制

```
推荐码机制：
1. 用户生成邀请链接
2. 好友通过链接注册
3. 好友完成首次付费
4. 邀请人获得VIBE奖励

奖励设计：
- 好友首次付费金额的50% = VIBE奖励
- 例：好友付49元 ≈ 100 VIBE
- 邀请人获得50 VIBE

合规注意：
- 单层奖励（不能多级）
- 奖励是Token，不是人民币
- 用户自愿参与
```
