## 核心原则

- 不做资金盘推广

- 记录「建设者」的故事

**特征：**

**特征：**
- 独立开发者、数字游民

**来源：**
- 技术博客

- Indie Hacker、V2EX 等社区
- YouTube/TikTok 科技频道

**获取方式：**
- 内容营销
- 社区口碑

### 第三层：潜在节点（10-50 人）

**特征：**
- 有 GPU 资源（个人矿机、小型数据中心、AI 创业公司）
- 对 AI 算力有需求或供给能力
- 愿意参与基础设施建设

**来源：**
- 算力需求方（AI 创业公司、研究机构）

**获取方式：**

## 冷启动策略

### 阶段一：造势（0-30 天）

**目标：让核心圈知道 USMSB 存在**

1. **GitHub 开源**
   - 整理核心代码，发布开源版本
   - 写好 README（讲清楚 USMSB 是什么，不是 ICO 是什么）
   - 提交到 relevant GitHub topics

2. **一篇重磅文章**
   - 「AI Agent 协作网络：为什么需要 USMSB」
   - 发布到：Twitter、Hashnode、Medium、独立博客
   - 核心：在 AI Agent 圈引发讨论

3. **定向邀请 20-50 人**
   - 给 AI Agent 领域的 KOL 发邀请码
   - 给他们「早期建设者」身份
   - 要求：体验产品 + 给出反馈 + 有价值时发 Twitter

### 阶段二：扩散（30-90 天）

**目标：建立第一批活跃社区**

1. **空投 VIBE（不是发钱，是发权益）**
   - 给早期注册用户空投 VIBE
   - 说明：VIBE 是网络的能量单位，不是炒作的币
   - 让收到空投的人有「这能干嘛」的探索欲

2. **任务挑战**
   - 「用 USMSB 完成第一个任务，获得额外 VIBE 奖励」
   - 截图发帖，带 #USMSB 标签

3. **建设者故事征集**
   - 邀请用户分享「我用 USMSB 做了什么」
   - 优质内容给予 VIBE 奖励和社区曝光

### 阶段三：节点启动（90-180 天）

**目标：开放算力节点认购**

1. **发布节点认购说明书**
   - 在社群和 Twitter 同步发布
   - 定向邀请有 GPU 资源的人

2. **节点体验活动**
   - 邀请 10-20 人免费测试节点
   - 收集反馈，优化体验

3. **正式开放认购**
   - 公布认购细节
   - 限时优惠，早鸟权益

## 让 VIBE「流动」起来

**不用「流动性」这个词。改成「让网络运转起来」。**

### VIBE 的自然流动场景

1. **Agent 完成服务 → 获得 VIBE**
   用户看到：我的 Agent 完成了一个任务，账户多了 VIBE

2. **使用其他 Agent 的服务 → 消耗 VIBE**
   用户看到：我的 Agent 调用了别人的服务，账户少了 VIBE

3. **质押给节点 → 获得任务优先权**
   用户看到：质押 VIBE 后，我的任务被更快处理了

### 怎么让流动加速

**早期策略：**
- 给所有注册用户初始 VIBE 体验金
- 让他们体验「支付 VIBE 使用别人服务」的过程
- 引导他们「我的 Agent 也想赚钱」的心态

**中期策略：**
- 算力节点上线，GPU 算力消耗 VIBE
- 任务越多，VIBE 消耗越多
- 供给侧（节点）和需求侧（任务）同时增长
