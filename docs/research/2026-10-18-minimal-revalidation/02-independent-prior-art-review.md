## 3. 数学主张逐项复核

### 3.1 DRD 映射与多动作条件：成立，非原创

定义某行动的决策区域为

$$R_{g,a}=\{h\in H:a\in A_g(h)\}.$$

对非空保留集 $C$，有

$$\bigcap_{h\in C}A_g(h)\ne\varnothing
\iff \exists a:C\subseteq R_{g,a}.$$

这直接还原 DRD 的停止条件。目标依赖只改变区域族；将它写成“目标等价”时须谨慎：$A_g(h)\cap A_g(h')\ne\varnothing$ 一般不传递，不能据此划分等价类。数学稿 §3 按全部允许观测核相等定义的 $\sim$ 才是真正等价关系。

HEC 的超边构造处理了重叠区域问题。因此不能把“消除成对冲突”概括为一般充分条件；需要整体交集或等价的完整阻碍结构。当前 SDK `evaluate()` 已使用整体交集，处理正确。

### 3.2 固定似然比与永久排除：主要证明成立

在固定 $h_*\in H$、固定已知核及正确条件观测模型下，对每个预先固定的 $j\ne h_*$：

$$M_t^{j,h_*}=\prod_{s\le t}\frac{p_{j,e_s}^{X_s}(1-p_{j,e_s})^{1-X_s}}
{p_{h_*,e_s}^{X_s}(1-p_{h_*,e_s})^{1-X_s}}$$

是从 1 开始的非负鞅。探针可以依历史和错误提示自适应选择，只要在取得该结果之前决定，且包含这些信息后的条件核仍正确。严格 $0<p<1$ 保证共同支持。

对 $m-1$ 个替代世界分别应用 Ville，再并界，确实得到

$$\Pr_{h_*}\{\exists t:h_*\notin C_t\}\le\delta,$$

阈值为 $\log((m-1)/\delta)$。永久排除对应“曾经越界”，已被该不等式覆盖。SDK 用全部假设的最大分数作比较，即使比较者以前被排除，也不损害这份证明。$m=1$ 没有竞争者，当前实现不排除唯一假设；这不验证其真实性。

需避免三种错误表述：

- $\max_j M_t^{j,h_*}$ 通常不是有效的单位初值 e-process；有效性来自逐项 Ville 加并界。
- 不需要对所有 $m(m-1)$ 对再并界以保护一个真实 $h_*$；但也不能解释为“以高概率所有假设都不会被排除”。
- 覆盖界不保证会停止、有限期望成本或探针近似最优。完全不采样也可保持覆盖。

### 3.3 所有时刻与自适应形式目标：成立，但语义不在证明内

在同一个事件 $\{\forall t:h_*\in C_t\}$ 上，任何非空全交集中的行动都属于 $A_{g_t}(h_*)$。因此可以在同一模型会话内改变形式目标，无须为目标次数另付并界。

但是该结论仅约束**提交给工具的集合映射**。若 AI 看完结果后把所有世界的 $A_g$ 改为包含自己想做的动作，集合论命题仍然成立，现实决策却没有新增可靠性。核、候选族、测量含义、真实联合机制变更不属于这个“免费目标修订”。同一目标版本号对应不同映射也应可追溯，否则无法事后核验所声明目标。

### 3.4 观测等价类与停止：§3 的充分条件成立

固定目标下，若每个允许观测等价类都有共同正确动作，且全部允许探针持续具有正采样频率，则与真世界不等价的有限候选会因正 KL 累积而最终被排除。配合真世界始终保留的事件，可有限停止。这里没有统一期望成本上界；有预算上限的实现可先用尽预算。

若目标无限修订，需对所有实际采用的目标保留相应交集条件；不能把对一个固定目标的停止结论直接升级为任意演化目标必能完成。若唯一有区分力的探针未获授权，相应世界仍不可辨；增加算力或反复解释不会改变这一点。

两不可辨世界的正确集互斥时，要求总能输出正确动作的错误率不能低于 $1/2$。三集合例则给出不同阈值，数学稿已经正确区分，没有错误套用二世界界。

### 3.5 两世界 KL 下界：成立，但不是完整的多答案下界

固定同一目标 $g$，令 $A_g(h)\cap A_g(h')=\varnothing$，取事件 $D=\{\widehat a\in A_g(h)\}$。若方法在两世界分别以至少 $1-\delta$ 停止且正确，$\delta<1/2$，则 $\Pr_h(D)\ge1-\delta$、$\Pr_{h'}(D)\le\delta$。满足顺序变测度条件时，Kaufmann 等 Lemma 1 直接给出数学稿 §4 的式子和成本推论。

必须明确：

1. 不能只要求“输出时的条件正确率”，否则永远拒答的零成本算法破坏该下界的作答前提。有限预算到期的 `inconclusive` 不能在这里算正确完成。
2. 常用引理对几乎必然有限停止时间陈述；若正概率永不停止且逐步成本有正下界，期望成本为无穷，下界虽真但没有效率含义。
3. 两世界须运行同一个可观测策略，收到的额外信息也要纳入轨迹。若提示直接泄漏变化位置，它本身提供信息，不能继续只计算付费探针 KL。
4. 对某个 $a\in A_g(h)$，未必有 $\Pr_h(\widehat a=a)\ge1-\delta$，所以不能随便把两世界事件换成单动作事件。动作集互斥保证了这里使用整个 $A_g(h)$ 的合法性。
5. 两两都相交、全体却无交集时，该简化下界可能完全没有约束，但问题仍需实验；不能据此得出零成本。完整多答案复杂度应比较 Degenne–Koolen，而非将成对 KL 的最大值称作最优复杂度。

### 3.6 Ω(M)：给定局部探针构造成立，不是任意变化定位定律

数学稿 §4.1 中，$M$ 是**候选变化位置数**；实际变化数至多 1。若无变化的 $h_0$ 与每个 $h_j$ 的正确动作集互斥，只有局部探针 $j$ 能区分两者，且方法在所有世界都满足作答与错误要求，那么对每个 $j$ 分别应用下界再求和，确得

$$\mathbb E_{h_0}\sum_jN_j\ge
M\frac{\operatorname{kl}(1-\delta,\delta)}{\operatorname{kl}(p_0,p_1)}.$$

这证明**无变化世界下，排查所有局部变化替代解释**需要线性成本。对于同一族，它也给出最坏情况成本下界；不能说在每个已变化的 $h_j$ 下定位都要同样成本。若目标仅区分保留/更换，发现任意一处变化已足够，不必恢复其余位置。

反例边界：允许有足够信息的组探针时，单一异常位置可用二分式查询降低查询数；所有候选共享一个正确补救动作时甚至可以零查询作答。精确复杂度还取决于组测试的噪声、成本和可用性。因此不要把该构造简写成“稀疏变化必然需要 Ω(M)”；应保留局部访问结构、固定信号差异、正确性和基准世界。

### 3.7 old/current 联合族：逻辑成立，不能倒置为机制证明

若所有候选在旧作用域上的核相同，则任何旧观察对这些候选的似然比都是 1。正确旧历史不会缩小当前变化的不确定性；这是数学稿 §6 的直接代数事实。

有用迁移要求旧观察确实限制当前相关机制，并且这种联系已包含在真实的联合族中。`old` 与 `current` 标签只选择不同观测核，不能发现未知变点，也不能证明哪段记录来自哪个稳定时期。若变化时刻或变化部件未知，须将其保留为不确定性，或取得额外有效证据；不能由 LLM 猜测后偷偷按已知事实路由数据。

## 4. 反例与遗漏条件

### 4.1 两两相交不等于全交

$A_g(h_1)=\{a,b\}$、$A_g(h_2)=\{b,c\}$、$A_g(h_3)=\{a,c\}$。每对相交但没有共同动作。若三者在所有允许探针上不可辨，任何随机输出分布对至少一个世界的正确概率不超过 $2/3$；均匀输出达到该上限。原因是每个动作最多在两个世界正确，对三个世界的成功概率求和至多为 2。

这是同时检验停止条件、不可辨性和成对下界不足的最小反例。当前 SDK 返回 `inconclusive`，正确。

### 4.2 族外世界不必报冲突；空集也不证明族外

模型只有成功率 0.2 和 0.8 两个世界，动作分别为 `a`、`b`；实际世界每次都成功，但真正有效动作是 `c`。三次成功后 $\log(L_{0.8}/L_{0.2})=3\log4>\log20$，工具排除 0.2 并输出支持 `b`，此后全成功不会制造空集。

更强的不可识别例：实际世界的所有可用观测核恰与 0.8 候选相同，但正确动作是 `c`。任何只看这些观测的检验都无法区分它们。绝对拟合检验也不能检测这种语义差异。

反方向，真世界也可能在概率至多 $\delta$ 的错误事件中被永久排除，随后集合为空。因此 `model_conflict` 只能表示“当前证据与保留机制无法给出结论”，不是已证明模型失配；没有冲突更不是已证明模型正确。主文 §2.2 的方向判断正确，产品说明应保留此限定。

### 4.3 同源记录重复计算：当前接口存在可复现边界缺口

`observe()` 以 `(probe_id, source_ref)` 去重，因此同一个 `source_ref` 换不同 probe ID 可以重复进入似然乘积。构造六个同作用域探针，每个在 $h_0$ 下概率为 0.5，在 $h_1$ 下为 0.9；把**一次实际硬币结果**以六个探针名提交，使用相同来源、不同 observation ID。

若唯一硬币为 1，工具计算 $6\log(0.9/0.5)\approx3.5267>\log20$，排除真实 $h_0$ 并支持仅在 $h_1$ 正确的动作。真实 $h_0$ 下该事件概率是 0.5，远高于 0.05。它违反了条件独立增量的模型前提，因此不反驳 Ville；但证明了当前入口的去重不足以强制该前提。

**重要接入项，非本轮产品修改：** 宿主应验证底层实验/回执身份及测量依赖，避免别名把同一观测变成多次试验。简单地对所有 `source_ref` 全局去重也未必正确：一份真实批次回执可以包含多个不同试验，需区分批次与原子观测。若把一份回执的多个相关测量都计入，须使用正确联合/条件核，而不能直接相乘边际 Bernoulli 似然。

SDK 注释已经将认证与完整流交给宿主，所以应将其报告为未由计算器封闭的接入风险；数学稿 §8 的“不重复计数”应限定为当前确实拒绝的同 ID 或同 probe/source 重放，不能概括为全部来源别名已被识别。

### 4.4 信息顺序、缺失与历史选择

有效性要求的是 $X_t\mid\mathcal F_{t-1},e_t$ 的正确核，不只是每条记录边际上看似 Bernoulli。用户背景、LLM 提示、伙伴策略、上一结果引起的环境反馈均可能改变条件核。未知相关性、选择性回传、结果出来后只登记成功、按最有利历史片段重放都会破坏证明。重复看同一条失败并不是新失败；等待回执也不是观测到零。

历史数据若用于设计当前有限族、估计核或筛选同机制子集，就不能未经选择校正又作为独立验证数据。已排除的世界在新机制会话中仍可能为真；禁止把旧 `retained_ids` 当作新模型的完整 $H$。新开多个会话、反复试到成功也不受单次 $\delta$ 自动统一保护，需要明确全局错误预算或其他有效组合。

### 4.5 错误提示只影响采样并不保证低成本

两个世界只在探针 `useful` 上不同，LLM 永远选择同分布探针 `irrelevant`。覆盖界仍成立，但没有有用结论，所有预算可以浪费。正频率覆盖可处理这一类不停止问题，但不能自动推出有限样本竞争比。对照应同时报告错误、结论率和总成本，不能把零错误的永久等待算成功。

若提示依赖尚未公开的实验真值或答案位置，则还可能违反信息模型、造成基准泄漏；“提示不能剪 H”本身不足以排除这类问题。

## 5. 工具接口的审查意见

| 项目 | 本次观察 | 可声称的边界 |
| --- | --- | --- |
| 排除规则 | 阈值与似然比方向一致，所有候选分数继续更新，排除不恢复 | 与固定族证明一致；不是对真实世界的模型覆盖检验 |
| 全交集与空集合 | 使用 `set.intersection`；保留集为空返回 `model_conflict` | 正确避免两两相交错误和空集上的空泛结论 |
| 目标修订 | 每次要求完整 H 的非空动作集，重新计算全交集 | 支持形式目标重评；不检查映射语义或修订权限 |
| old/current | 校验 probe 的 scope；相同旧预测不能产生区分 | 字符串一致性是契约检查，不是机制不变证明 |
| 来源 | 同 ID 内容变化被拒，同 probe/source 重放被拒 | 跨 probe 的同源复用缺口见 §4.3；真实来源和条件核仍靠宿主 |
| 授权与预算 | 函数内限制 allowlist 与累计登记成本，返回 `authorization=not_provided` | 不能代替执行前授权；缺省 allowlist 覆盖模型中的所有 probe，接入层不能将其等同外部权限 |
| 快照 | 摘要校验模型；恢复时重新计算证据并使用宿主给定限制 | 摘要不是签名；伪造、删改、挑选或重排观测历史需宿主保证，不能靠 restore 认证 |
| 成本 | `registered_probe_cost` 为已登记观察的名义成本 | 未包括失败/未回传执行、模型推理、人类补救和旧证据沉没成本；不是完整现实成本 |

这份库有意不执行外部操作，保持其工具定位是合理的。应把缺失保证写进接入契约和实验评估，不应为了补齐审计表格写一套固定语义规划器。

## 6. 本轮实际验证

使用本机 Python 3.11、`-B` 禁止生成字节码，以独立模块方式加载上述 SDK 文件；无网络、模型、产品状态写入，未新增测试文件。五个内存构造结果：

| 构造 | 实际输出 | 解释 |
| --- | --- | --- |
| 三个两两相交但整体无交的动作集合，0 个观察 | `inconclusive`，共同动作为空 | 全交集实现正确 |
| 模型 0.2/0.8，连续三次成功 | 仅保留 0.8，`conditional_conclusion`，动作 `b` | 演示族外世界可能有条件结论而无冲突；这条序列本身也可能来自族内世界 |
| 六个不同 probe ID，共用一次成功结果和同一 source_ref | 六条均被接受；仅保留 0.9，结论 `b` | 复现跨 probe 同源重计；错误概率推断来自上述一次硬币构造，不是 Monte Carlo 估计 |
| 旧概率均为 0.8，当前概率分别 0.8/0.2，提交 20 条旧成功 | 两世界均保留；分数均约 -4.4628710263 | 旧数据未区分当前变化 |
| 0 个观察，旧目标两世界共享动作；新目标动作互斥 | 从 `conditional_conclusion` 变为 `inconclusive` | 目标重评不沿用旧目标结论 |

这些检查验证具体公式与接口行为，不验证真实 AI 的探针选择、现实机制校准、迁移收益或长期效果。没有重复实现主任务，没有运行付费实验，也没有将测试数量作为智能证据。

## 7. 无证据不可声称与下一步审稿问题

目前可说：实现了一个固定有限模型下、允许自适应探针与形式目标重评的条件证据计算器；主要覆盖证明可由既有理论直接导出；若干重要反例已经明确并有局部复现。

目前不可说：首次提出决策相关再验证；新发现多答案识别理论；贪心近似最优；错误提示无成本；未知变化已被可靠定位；未冲突即模型正确；版本/哈希证明机制相同；任何目标或新伙伴都能迁移；当前保证覆盖任意 LLM 生成核；26 项工程测试证明真实 AI 已学会；已产生用户净收益或达到 AGI。

下一步审稿应按以下问题取证：

1. **表示来自哪里？** 谁给出 H、观测核和动作集合？已知核实验是否明确标为理想化条件？自由提出的新解释、测量定义和未列机制如何接受反证，而不伪装为已有保证？
2. **变化真正未知吗？** AI 是否从文件名、scope、提示、候选排序或回执得到真实变化位置？是否同时包含无变化、不可辨、无授权探针和新机制？
3. **复用依据是什么？** 是否保存预先指定的联合模型、原始记录和机制联系？同机制仅是外部假设还是有验证？未通过验证时是否如实降低结论而非套用旧置信度？
4. **输入能否破坏统计前提？** 跨 probe 重计、相关回执、删报、伪造快照、历史择优和跨会话重复尝试是否在真正宿主入口受控？本次发现需要由实施者处理或明确留作未达项。
5. **省成本的比较公平吗？** 所有策略是否共享观测接口、权限、历史、预算和错误口径？成本是否包含未完成试验与推理？是否与适用的 DRD/纯探索方法比较，而不仅是完整识别或均匀探索弱基线？
6. **拒答如何计分？** 错误率、结论率、达到结论的成本、预算耗尽和永久不可辨应共同报告。不能只统计成功停止的试验，也不能只比较条件错误率。
7. **真实 AI 有何新证据？** 不提供参考步骤，保留实际输入、工具选择、反证后的变化、失败及成本；区分无记忆、盲信历史、无提示、坏提示等对照。脚本策略和当前研究代理的分析不算产品运行证据。
8. **贡献到底是哪一层？** 若声称新理论，给出相对前驱真正新增的假设族、命题和证明；若是系统贡献，就展示授权接口、证据迁移和真实 AI 使用的可复现改进。真实用户价值仍需另一层外部效果证据。
