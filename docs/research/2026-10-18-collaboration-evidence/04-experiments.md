# 实验协议与复现说明

日期：2026-10-18。性质：离线合成研究，不是真实 Agent 行为或商业效果实验。

## 1. 要证伪什么

本协议在本轮第一次模拟运行前写下，随后随研究提交保留。它不是外部注册的预注册研究，也不掩盖开发时的错误修正。方法对应 [数学结果](03-mathematical-results.md)。

待检验预期：

- H1：在假设成立的有界合成数据上，同时置信区间应包含真实均值；错误签发率不应与声明的失败预算明显冲突。
- H2：选择性缺失可让只统计已完成者的方法稳定误判。
- H3：目标仅为已测维度的重新加权时，保存向量证据可复用；旧标量分数不能替代它。
- H4：如果输入了错误的漂移界，本研究方法也会失败。
- H5：该方法可能很保守；面对有限样本的小增益，拒绝签发可能使有效机会流失。
- H6：在已有试验的待回传结果中补充观测，可缩小区间；这不等同于提高经济收益。

## 2. 固定设置

- 伪随机基础种子 `20261018`；每个场景和重复次数派生独立固定种子。
- 每个随机场景 `400` 次重复；每个候选 `4096` 次登记；两个结果维度。
- 检查点为 `32, 128, 512, 2048, 4096`。模拟中的“任意时刻”错误率仅在这些检查点检查；连续所有前缀的保证来自证明，不是这个有限模拟。
- 每个重复使用总失败预算 `delta=0.05`，覆盖该重复的候选与维度，不声称覆盖全部 400 次重复的联合事件。
- 各结果坐标按给定均值独立 Bernoulli 生成，候选结果也独立。模拟为比较方法提供相同数据，不表示现实可同时取得全部候选的反事实结果。
- 每个检查点检查完整向量覆盖，故也覆盖任何以这些资料选出的线性目标。另设目标自适应挑选的零增益压力场景。
- 不进行超参数搜索，不隐藏失败种子，不以随机模拟证明原创性。

## 3. 场景

| 场景 | 真值与观测机制 | 应关注的结果 |
| --- | --- | --- |
| stable_gain | 基线 (0.45,0.45)，候选 (0.85,0.70)，权重 (0.75,0.25)，候选额外成本 0.05，全部回传 | 方法应能识别较大正增益；记录首次签发样本数 |
| selective_missing | 基线 (0.60,0.60) 全部回传，候选 (0.35,0.35) 只有成功可见 | 只看完成者会错选；如实计入未回传者应不签发虚假增益 |
| revised_goal | 基线 (0.5,0.5)，A (0.9,0.1)，B (0.1,0.9)，目标由第一维改为第二维 | 冻结旧标量会选 A；向量证据可支持 B |
| stale_environment | 基线 0.5，候选旧样本均值 0.85，当前真值 0.25 | D=0 应失败；候选 D=0.60 的显式敏感性界可防过度自信 |
| small_gain | 基线 (0.50,0.50)，候选 (0.54,0.54)，全部回传 | 记录保守方法错失机会，不只报告少犯错 |
| adaptive_null | 三方案均值均为 (0.5,0.5)，每次看数据后选择最有利的单一维度作为目标 | 原始点估计可能挑出“赢家”；本方法不应轻易签发 |

另外做两个确定性构造：

1. 从未测到的新目标维度：构造可见数据完全相同、真实增益相反的两个系统。
2. 补充观测：固定登记数，候选成功结果暂不可见；按登记顺序查明待回传记录的 0%、25%、50%、100%，比较区间与额外观测数。此处查明总能成功且免费只是实验设定，现实不保证。

## 4. 对照与消融

- `baseline_only`：始终不升级，暴露“永远不犯切换错误但完全不创造增益”的退化解。
- `completed_only`：按当前目标，只统计已完成结果的点估计。
- `frozen_goal`：仍按旧目标选择，用于目标修订消融。
- `vector_certificate`：本文的向量、时间并界、缺失补全方法。只有相对基线下界为正时，实验选择候选；这是为了测量证据签发行为，不是产品强制路由。
- `drift_envelope`：漂移场景另加正确 0.60 包络。这个包络由实验构造给定，不是学习到的漂移侦测器。

不把这些简单对照当成领先算法。尚未完整复现 OPSE 的在线淘汰、最新置信序列、后继特征或安全离线 RL；因此不得发布“优于现有技术”的结论。

## 5. 必须保留的指标

每种方法报告最终选择的真实期望净增益、非正增益选择次数、负增益选择次数、正增益被选次数、无结论次数，以及首次签发检查点。

区分：

- `nonpositive_switch`：选了真实期望增益不大于零的候选。
- `harmful_switch`：选了严格负增益的候选。
- `positive_switch`：选了正增益候选。
- `baseline`：未切换，既不算成功学习，也不自动算错误。
- 覆盖失败：任一检查点、任一维度真实当前均值不在区间内。

报告总登记样本量。模拟的 Bernoulli 试验不是零成本真实模型调用；不能按模拟中的收益计算实际 ROI。对重复频率给 Wilson 95% 区间；它描述 Monte Carlo 频率不确定性，不是实际系统的保证。

## 6. 复现方式

实验实现置于 `experiment/`，只依赖 Python 标准库，兼容 Python 3.11+，不导入需要 Python 3.14 的 USMSB SDK。

复现命令（在本研究目录运行）：

```console
python -m unittest discover -s experiment -p "test_*.py" -v
python experiment/run_experiments.py
python experiment/run_experiments.py --check
```

生成 `results/summary.json`、逐重复明细 `results/trials.jsonl` 和 `results/report.md`。`--check` 应重新计算并逐字比较已提交的结果，差异时非零退出。全部结果为合成数据，不含账户、密钥、生产事件或个人资料。

## 7. 结果与解释

协议先保存在提交 `2ccea6a`，之后才实现和运行模拟；没有因结果而调整均值、种子、检查点或样本量。生成结果见 [报告](results/report.md)、[汇总](results/summary.json)、[逐重复明细](results/trials.jsonl)。

| 检验 | 观察结果 | 有限结论 |
| --- | --- | --- |
| 大增益 | 本方法 400/400 选择正增益候选，最终期望增益 0.3125 | 在这个易分离、稳定的实例中有效；不是商业 ROI |
| 坏结果不回传 | 完成者统计 400/400 选错，本方法 0/400 选错 | 计入缺失很重要；不证明优于已有 OPSE |
| 目标重加权 | 旧目标对照 400/400 选错，向量方法 400/400 选择新目标的有效候选 | 已测维度的复用有效；未覆盖新语义或新目标生成 |
| 环境突变 | D=0 的本方法 400/400 选错；给定正确包络后 0/400 选错 | 包络是关键假设，不是自动学习能力 |
| 小增益 | 本方法 400/400 留在基线；点估计 400/400 选择 +0.04 候选 | 严格但保守，存在明确的机会成本 |
| 数据后挑目标的零增益场景 | 点估计最终 355/400 选出非正增益候选；本方法 0/400 | 同时覆盖有意义；不能把“零增益”直接称作事故 |

满足模型假设的场景中，本方法未在检查点出现覆盖失败。0/400 的频率 Wilson 95% 上界约 0.9512%，不是错误概率为零。违反漂移假设的场景保留全部失败，不能从总表里删除。

补充观测构造中，全部 3,276 条待回传记录查明后，增益下界从负数升为约 0.1985；该构造没有计真实观测费用。未测新目标维度则仍为 [-1,1]，不因记忆已有第一维而变得已知。

## 8. 执行与复核记录

- 环境：Windows，Python 3.11.4 标准库；不安装依赖、不启动 SDK 或服务。
- 初次执行：15 项单元检查通过；运行器因嵌入式 Python 不自动加入脚本目录而导入失败，未生成模拟结果。显式加入本脚本目录后运行成功。这是运行环境修正，不是实验调参。
- 实际样本：6 × 400 次模拟重复；各臂登记数固定为 4,096；总合成登记数 22,937,600。每次登记含两个独立生成的结果坐标。
- 随机实验不是在线探索策略比较：所有方法读取同一批等量模拟试验，学习成本尚未优化。旧环境／旧目标场景是对历史样本的再评估，不是完整社会动力学。
- 没有模拟真实 Agent 的谈判、方法创造、内生目标形成或独立主体利益。候选只是有给定分布的研究对象，不是伪装成 AI 的业务脚本。
- 全部数值检查不能取代证明；本轮尚无独立数学审稿。

最终复现与文件审查结果见下面的收尾记录；未完成项目在 [下一阶段路线](05-roadmap-and-product.md) 中保留。
