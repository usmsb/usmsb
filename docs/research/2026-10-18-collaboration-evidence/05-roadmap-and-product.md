# 从研究命题到技术与商业价值

日期：2026-10-18。本文件是下一阶段研究与验证设计，不是本轮已实施功能清单。

## 1. 对 USMSB 六种逻辑的具体承接

| 逻辑 | 本命题如何触及它 | 不能以什么冒充完成 |
| --- | --- | --- |
| 目标—行动—结果循环 | 区分目标版本、行动安排与结果事实；目标改变后检验旧证据 | 改验收标准宣布旧目标成功 |
| 资源—转化—价值增值链 | 把协作、观测、模型、人类救场、延迟及失败计入成本 | 只报产物数或忽略验证费用 |
| 信息—决策—控制回路 | 判断信息是否能支持选择；主动取得缺失事实 | 把 LLM 的合理解释当现实结果 |
| 系统—环境互动 | 检查经验的适用环境与漂移；必要时重新试验 | 固定成功率永久适用 |
| 涌现与自组织 | 允许主体自选伙伴、提出方法并拒绝；观察形成的合作结构 | 预置流水线、同控多实例冒充独立生态 |
| 适应与演化 | 检验经验是否改变后来行为，并在新条件下仍有增益 | 保存记忆、生成复盘报告即宣称学会 |

九要素用于发现盲点：谁有权、作用于什么、追求什么、资源与规则如何约束、信息从哪里来、谁得益、谁担风险、环境如何变化。十行动可以交错、并行、被省略，不要求每轮走十步。

## 2. 下一项真正值得竞争的科学问题

目前的证据界只是基线，而且保守。更有竞争力的问题是：

> 当旧经验只部分适用于新目标、反馈可能选择性缺失且取得反馈有代价时，能否学习一种由语义理解辅助的观测与合作策略，以更少的现实试验获得同样可靠的决策？

可以先在受控模型中研究如下优化对象：

\[
\min_\pi \ \mathbb E[C_{\rm action}+C_{\rm observation}+C_{\rm compute}+C_{\rm human}]
\quad\text{subject to}\quad
\Pr(\text{错误签发正增益结论})\le\delta,
\]

并要求在明确的可识别、正增益实例族中有足够的发现率／有限停止时间；否则“永远不行动”就是没有价值的平凡解。不可识别实例必须允许返回“当前无法确定”。

这不是已给出算法的最优化问题。策略还需权衡错失机会、探索损失和时间价值。把所有成本相加也要求可解释的单位转换；不能把人类意义全折成钱。

潜在科学贡献的合格形式至少有一项：

1. 一个现有方法没有覆盖、但真实任务确实满足的结构假设，以及相应可识别条件或不可能性界。
2. 在同样假设和可靠性要求下，更低的观测／试验复杂度，有匹配对照及反例。
3. 有效的跨目标、跨主体迁移保证：明确何时可共享经验、何时应拒绝迁移，且不能使用评估集泄漏取得优势。

**不合格形式：** 九要素加权评分；换名字的 UCB；“加入记忆所以进化”；把复杂系统中的全部行为假设为同一个奖励；一组模拟数字自动升级为新科学。

## 3. AI-first 的技术结构

### 3.1 智能主体负责语义与研究

实际运行的 Agent 根据获准的目标、上下文、资源和伙伴条件，提出可解释的行动与合作假设；可选择独立完成、提出新能力、找伙伴、补证据或暂停。它不必为每个动作先请人派单。

AI 必须判断：

- 当前目标是否只是旧指标重加权，还是新增了需要测量的意义？
- 两组记录是否真正可比，是否存在隐含人力、选择偏差或干扰？
- 哪个反馈来源可信，什么观察才算真实结果？
- 下一次行动是在创造价值，还是在为未来学习取得信息？
- 现有技能、工具与伙伴是否足够，能否创造一种新的方法？

这些问题不由开发者写业务分类器代答。AI 的解释是待检验假设，不因为来自模型就可信。

### 3.2 数学与基础设施负责可核对边界

可选工具对获准数据计算估计、识别集合、区间、敏感性或实验成本。工具应清楚返回假设与未覆盖因素，而不是输出一个伪装为客观真理的“最优合作伙伴”。

Wishbud 保存来源、版本、承诺及获准共享的记录；OPC 和其他 provider 提供实际能力及原始回执；独立 Agent 保留自己的模型、记忆、拒绝和退出权。Morrow 负责人与其智能伙伴的持续交互。

新方法或新工具不能自行授予外部访问、付费、发布或数据共享权。目标修订不能抹掉已签约的旧责任；实验预算与执行授权分别受确定性边界约束。

### 3.3 新结果维度不靠新增一个业务模块

AI 可以提出新的测量定义或生成获准工具，但应建立新版本、列明证据来源、先验证测量是否反映现实，再处理旧资料能否重测。旧统计保证不会自动继承。

如果还没有可验证测量，就保留自然语言判断和不确定性，而不是把所有事情塞进一个评分表。某些追求不适合大量试错；这时可使用领域知识、协商或专家判断，但必须如实说明证据类型。

## 4. Morrow 应让人感受到什么

不是新建“统计研究驾驶舱”。人在追求中应收到直接、有依据的解释，例如：

> 你现在更重视长期留存。之前的点击结果不能证明这一点。我找到一部分已获准使用的后续记录，但还有结果未到，现阶段不能说方案 A 更好。我会先核对这些结果，再决定是否继续投入；不会增加投放或对外发布。

这只是交互设计示例，不是强制话术或本轮已发生的产品行为。正常情况下 AI 也应能直接推进明确获准、证据足够的工作，不要把“无法证明”变成永远不做。

用户看见的是：当前在为什么努力、已有什么真实变化、准备怎么做、哪些承诺需要自己决定。对于目标版本和证据的细节按需展开。不能让用户填写九要素或每次做统计选择。

## 5. 商业价值从哪里来

候选价值主张：**让持续使用 AI 的个人与小团队少做无效合作和重复试错，更可靠地获得可用成果。** 不是卖“保证赚钱”，也不是只卖审计报表。

第一批研究参与者应符合已讨论的产品方向：数字化素养高、能自助使用和创作，有重复但并非完全相同的真实工作，有可取得的结果反馈。任务样本可以跨内容、软件与研究；共同点是可检验的反馈，而非相同页面或固定流程。

需要警惕：一个人的少量、长期、一次性目标可能根本没有足够统计样本。冷启动时不能假装已有个人学习；更不能未经验证就把别人的经验视为适用。可先利用既有模型能力创造即时价值，逐步积累有授权、有适用依据的经验。

### 5.1 必须比较的总成本

\[
\text{净增益}=
\text{实际采用成果的增量价值}
-\text{执行、模型、观测、协调、人类补救和机会成本的增量}.
\]

比较对象应是同样能访问基础模型和工具的强单 Agent 或用户当前最佳做法，而不是只与“完全不用 AI”相比。等待时间、失败返工和外部负影响必须单列；某些损害不能货币抵消。

仅作为敏感性算例：若一次有效决策节省 20 个价值单位，额外评估平均花掉 30，方法即使更准确也可能不值得卖；若可复用的观测把额外成本降到 2，才值得进一步验证。这不是市场报价、收入预测或本轮实测。

### 5.2 产品与收入假设

先通过 Morrow 的持续成果验证付费意愿，再考虑把成熟学习能力向其他 Agent/Harness 提供服务。可以测试订阅或按实际资源计费，不应在价值归因尚不可靠时宣称按收益分成已经成立。

商业优势可能来自低验证成本、真实成果反馈、用户信任、可解释的迁移和稳定运行；不是协议封闭、扣留数据或要求所有人加入同一经济体系。

## 6. 分阶段交付与止损标准

| 阶段 | 实际交付物 | 通过条件 | 失败后怎么办 |
| --- | --- | --- | --- |
| R0：本轮基线 | 查新、证明、反例、离线实验与全部种子 | 可复现，边界明确，承认已有前驱 | 先纠正数学与实现，不进生产 |
| R1：科学复核 | 独立数学审阅；OPSE、置信序列、昂贵反馈与多目标方法同条件复现 | 无关键漏洞；明确非平凡差异，否则取消原创主张 | 使用已有最优方法，不为新名字造算法 |
| R2：AI 行为验证 | 真实外部 Agent 自主提出方法、识别新目标信息缺口、选择反馈；保留全部轨迹与成本 | 未提示参考动作，遇反证能改变行为，结论校准优于强对照 | 区分缺信息、语义误解、工具不足与模型能力不足 |
| R3：真实价值试点 | 自助用户真实工作，对照设计与结果随访 | 预设净增益标准、置信区间和风险约束通过，用户愿意继续使用 | 停止扩量，不用 UI 活跃掩盖无收益 |
| R4：迁移与规模 | 跨目标、模型、伙伴和环境的留出评估；独立参与方 | 优势在新组合下仍成立，成本随规模可承受 | 缩小可声称的适用范围，不收窄开放架构 |

R1 首先检查本文组合是否已被更一般的理论覆盖；有则老实采用。R2 先使用现有 AI/Harness 和工具，不预写“正确行动步骤”。未来是否训练表示、校准器或策略，应由真实行为缺口决定。

R3 不指定拍脑袋样本量。先用探索性试点估计方差和实际最小有用增益，再确定功效、聚类／干扰处理、停止准则和完整成本记录。少量好评与同控多个实例不构成独立统计证据。

## 7. 尚未解决的问题账本

- **内生目标形成：** 本轮只允许已授权目标变化，不解释追求如何产生、协商或改变合法性。
- **结构学习与迁移：** 相同标签不等于相同机制，目标、伙伴或模型版本变化后怎样可靠复用还没有算法保证。
- **干扰与非平稳：** 合作会改变后续环境；简单样本均值不足以解释长期互动。
- **观测可信性：** 自报结果、模型评分和现实效果可能不同；主动验证本身也可能带来选择偏差。
- **激励与策略操纵：** 供给方可能挑任务、迟报坏结果、优化代理指标；当前区间不解决串谋和欺骗。
- **低成本：** 当前保守界可能需要大量样本；真正商业化前必须解决。
- **价值不可完备测量：** 不能把未测外部性视为不存在，更不能代替受影响主体的权利。

## 8. 本轮收尾准则

研究扩展的是主体对经验有效性的辨别与求证空间；没有把选择目标、伙伴或方法的权力移交给代码。当前研究 Agent 的推导与模拟不是 Morrow 的运行证据。

软件测试、真实 AI 行为和外部实际效果必须分别举证。本轮只完成研究与离线基线；下一步首先争取独立复核和真实学习效率，而不是继续增加业务模块。
