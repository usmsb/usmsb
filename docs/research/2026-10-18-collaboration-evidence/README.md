# USMSB 研究：可修订目标下的证据驱动协作学习

整理日期：2026-10-18。状态：研究草案与可复现基线，不是已发表成果、AGI 声明或生产能力说明。

## 选定的命题

**在目标可修订、主体可变化、真实结果部分可见且可能选择性迟到的条件下，智能主体能否以可核对的证据，学习何时独立行动、何时合作、何时补充观测，并将经验迁移到新的追求？**

这是本轮主观选择的最值得优先投入的研究方向，不是经过统计证明的“成功概率最高”方向。它面向组织协作、科研、工程和经济活动，不以某个 IT 场景定义 USMSB。

首个可分析子问题：**目标改变以后，哪些旧经验还能支持“这个合作方案优于基线”的判断？如果反馈缺失，什么情况下即使增加算力也无法判断？**

不是把协作编成固定流程。AI 负责理解、提出方案、寻找伙伴、解释变化及选择实验；数学工具帮助它区分事实、估计、假设和不可识别部分。不能把这个局部统计模型当成整个 USMSB。

## 本轮交付边界

- 将近期关于社会价值、科学定位、技术壁垒和数学化的讨论整理为研究记录；不是完整逐字聊天记录。
- 推导可识别性、序贯证据区间、目标修订复用及缺失信息边界。
- 提供独立、离线、标准库实验；不接触生产资料，不调用付费模型，不修改 SDK/Morrow 运行时。
- 所有定理的正确性以明示假设为条件；尚未经独立数学审稿或形式化证明。
- 查新已发现大量直接前驱。本轮不能宣称原创科学突破、专利新颖性或商业护城河已经成立。
